## EEG During Mental Arithmetic Tasks Dataset by PhysioNet

The database contains EEG recordings of 36 (00 to 35) subjects before and during the performance of mental arithmetic tasks. Each subject has 2 files:
  1.  With "_1" suffix -- the recording of the background EEG of a subject (before mental arithmetic task)
  2.  With "_2" suffix -- the recording of EEG during the mental arithmetic task.

Data is in the [Arithmetic task dataset csv](../master/Arithmetic%20task%20dataset%20csv) file folder.
